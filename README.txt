NEON FOUR : COSMIC OVERDRIVE
실행 및 Assets 연결 안내

[파일 구성]
- index.html
- README.txt
- assets/  (이미 추출해 둔 Assets 폴더를 index.html과 같은 위치에 둡니다.)

[실행 방법]
1. index.html과 assets 폴더를 같은 상위 폴더에 둡니다.
2. 아래 목록의 파일명이 assets 폴더 안의 실제 파일명과 일치하는지 확인합니다.
3. index.html을 브라우저에서 엽니다.

[중요: Base64와 Assets 연결]
원본 HTML 안에 들어 있던 이미지·음원 Base64 데이터 URI를 상대경로 assets/파일명으로 교체했습니다.
따라서 Base64 문자열을 별도로 붙이는 방식이 아니라, 브라우저가 assets 폴더의 실제 파일을 읽는 방식입니다.
파일명 또는 확장자가 다르면 해당 파일명을 아래 목록과 맞추거나 index.html 안의 경로를 실제 파일명으로 수정해야 합니다.
